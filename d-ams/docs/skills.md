# Agent Skills Definition

## Shared Skills (Available to All)
*   **Context Management:** Ability to read and write to the shared project documentation and codebase.
*   **Report Generation:** Summarizing work done and issues encountered for the Leader.

## Leader Agent Skills
*   **Strategic Planning:** Breaking down a high-level goal into a sequential task list (WBS).
*   **Orchestration:** Selecting and invoking the right Worker Agent for a specific task.
*   **Conflict Resolution:** Weighing conflicting technical opinions (e.g., DBA vs Backend) and making a final decision.
*   **Product Packaging:** Compiling code, documentation, and assets into a final deliverable.

## Tech Lead Skills
*   **Architectural Design:** Creating high-level system designs and patterns.
*   **Code Review:** Identifying security flaws, performance bottlenecks, and style violations.
*   **Risk Assessment:** Identifying potential technical debt or scalability issues early.

## Backend Developer Skills
*   **API Implementation:** Writing clean, documented REST or GraphQL endpoints.
*   **Business Logic:** Translating requirements into functional code.
*   **Integration:** Connecting the application to databases, third-party services, and internal modules.

## DBA Skills
*   **Schema Design:** Creating ERDs and SQL/NoSQL schemas.
*   **Query Optimization:** Indexing and tuning queries for performance.
*   **Migration Management:** Designing safe data migration paths.

## QA/QC Skills
*   **Test Planning:** Designing comprehensive test cases covering edge cases.
*   **Automated Testing:** Writing unit, integration, and E2E tests.
*   **Bug Tracking:** Identifying, documenting, and verifying fixes for defects.
