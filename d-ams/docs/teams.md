# Team Composition Templates

These templates serve as a guide for the Leader Agent during the **Team Assembly** phase.

## 1. Web Application Team
*   **Target:** SaaS, Portals, REST APIs.
*   **Composition:**
    *   **Core:** Leader, Tech Lead, QA/QC.
    *   **Specialized:** Backend Dev, Frontend Dev, DBA.

## 2. Mobile Application Team
*   **Target:** iOS, Android, Cross-platform (Flutter/React Native).
*   **Composition:**
    *   **Core:** Leader, Tech Lead, QA/QC.
    *   **Specialized:** Mobile Dev, UI/UX Designer, Backend Dev (for API).

## 3. Systems & CLI Tools Team
*   **Target:** System utilities, DevOps scripts, Compiler tools.
*   **Composition:**
    *   **Core:** Leader, Tech Lead, QA/QC.
    *   **Specialized:** Systems Programmer, Tech Writer.

## 4. AI & Data Engineering Team
*   **Target:** Data pipelines, ML models, Analytics dashboards.
*   **Composition:**
    *   **Core:** Leader, Tech Lead, QA/QC.
    *   **Specialized:** ML Engineer, Data Scientist, DBA.

## 5. Game Development Team
*   **Target:** 2D/3D Games, Interactive Simulations.
*   **Composition:**
    *   **Core:** Leader, Tech Lead, QA/QC.
    *   **Specialized:** Game Developer, Game Designer, Asset Specialist.
