# Agent Directory & Classifications

Agents are categorized into **Core Leadership** (constant for all projects) and **Specialized Workforce** (assigned based on product type).

## Core Leadership Agents
These agents provide the foundation for any project.

### 1. Leader Agent (Gemini/Command Center)
*   **Role:** CEO & Orchestrator.
*   **Responsibility:** Project strategy, **Team Assembly**, and final delivery.
*   **Authority:** Absolute.

### 2. Tech Lead Agent
*   **Role:** Chief Architect.
*   **Responsibility:** High-level design validation and cross-domain code review.
*   **Specialty:** Can adapt standards for Web, Mobile, or Systems.

### 3. QA/QC Engineer Agent
*   **Role:** Quality Gatekeeper.
*   **Responsibility:** Testing the product against its specific domain standards (e.g., UI testing for Mobile, Load testing for Web).

## Specialized Workforce Agents
Selected dynamically by the Leader Agent.

### A. Web/Backend Specialists
*   **Backend Developer:** Logic, API, Server.
*   **DBA:** Schema design, SQL optimization.
*   **Frontend Developer:** UI implementation (React, Vue, etc.).

### B. Mobile Specialists
*   **Mobile Dev (Swift/Kotlin/Flutter):** Building for iOS/Android.
*   **UX/UI Designer:** Creating interactive prototypes and design systems.

### C. Systems & Tools Specialists
*   **Systems Programmer (C++/Rust/Go):** Building high-performance CLI tools.
*   **Technical Writer:** Crafting man-pages and developer documentation.
*   **DevOps Agent:** CI/CD pipelines and deployment automation.

### D. Game Development Specialists
*   **Game Developer (Unity/Unreal/Godot/JS):** Implementing game logic, physics, and mechanics.
*   **Game Designer:** Defining gameplay loops, level design, and balancing.
*   **Asset Specialist (2D/3D/Sound):** Managing visual assets and audio integration.
